# B06 S4-A02 — source-bound independent project plate calculation

Date: 2026-10-10. Input: synthetic project; no real project file or authorized engineering approval provided.

## Implemented behavior

`prepareProjectShellSource` validates the S4-A01 project/plate contract before producing its rectangular mesh, explicit edge restraints, material and separated load components. Mesh node/element identities derive from the persistent plate ID; their owning source record binds the project, revision, plan/placement basis, plate and optional provenance element references. Those references are not shared structural DOFs or proof that a column provides an edge restraint.

`recordProjectShellSource` creates `ARKEM-PROJECT-SHELL-SOURCE-RECORD/1.0` with a SHA-256 identity over the canonical declaration and prepared mesh/load data. Reference arrays are canonically ordered. Source identity changes when geometry, material, loads, mesh, support or provenance changes.

`recordProjectShellCalculation` creates `ARKEM-PROJECT-SHELL-CALCULATION-RECORD/1.0`, retaining that source record and every load case's raw nodal displacement/reaction/load and Gauss-point strain/resultant values. Its seal covers formulation, source, results and deterministic solver diagnostics; elapsed time alone is outside the seal. `verifyProjectShellCalculation` hashes the content and recomputes the current declared source, rejecting a fabricated result even if its hash was recomputed.

The physical mesh and MITC4 numerical kernel are shared with the existing S2 engine. A project source is never converted into a synthetic fixture. The legacy synthetic-only API still rejects project sources and its four medium-grid calculation identities are preserved exactly. The shared physical kernel alone confers no project binding or approval.

Loads are G_SW, G_SUP, Q, BENCH and derived G. G_SW uses declared unit weight and thickness; frame allowance and frame nodal transfer are excluded. This is a separate plate under explicitly declared SS-H/CL boundary conditions, not a coupled building model. Both full-building and technical-approval flags remain false.

## User flow

On `/plan-ve-aks`, save a valid project shell source, then select **Proje döşemesinin kabuk hesabını çalıştır**. A disposable worker keeps the page responsive, with cancellation and a bounded execution time. The screen shows source/calculation IDs, project/revision/plate, mesh size, area, center/maximum vertical displacement and force/moment equilibrium residuals for every declared load case.

Results are held in the current session. Source changes or plate selection changes remount the calculation session and terminate an active request. Invalid/stale source data expose no calculate action. Reload requires a new calculation. No raw result is placed in the existing localStorage project envelope. Durable storage is S4-A03; project JSON/PDF/DXF document linkage is S4-A04.
